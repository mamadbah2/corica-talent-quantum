## 7. Motif de marque — analyse & reproduction

Le motif (présent sur véhicules, cartes de visite, supports, pas seulement le web) a été récupéré et analysé.

**Géométrie mesurée (sur le fichier original `Corica-pattern-strip.png`, 6672×122 px) :**
- **Tirets diagonaux arrondis** orientés à **±45°**, en **tissage** (deux directions entrelacées).
- **Épaisseur de trait ≈ 11 px** (sur 122 de haut), extrémités **arrondies** (round cap).
- **Longueurs variées** : carrés/points (~11 px) + barres moyennes (~32 px) + longues barres, rythme pseudo-aléatoire.
- **Couleur unique** : orange **`#F26322`** sur **transparent**. Couverture ≈ **41 %**.

**Fichiers livrés (`brand-assets/`) :**
| Fichier | Nature |
|---|---|
| `corica-pattern-strip.png` | **Original exact** de marque (pixel-perfect, mono-orange transparent) |
| `corica-pattern.svg` | **Reproduction vectorielle** tuilable, légère, recolorable |
| `corica-pattern.css` | Helper CSS : 3 méthodes d'usage |
| `motif-demo.html` | Démonstration (variantes recolorées) |
| `pattern-vs-original.png` | Comparaison repro vs original |

**3 façons de l'utiliser (toutes locales, air-gap) :**
1. **Exact** : `corica-pattern-strip.png` en `background` (orange tel quel).
2. **Exact + recolorable** ⭐ : le PNG en **`mask`** → le motif prend n'importe quelle couleur (`background-color`) tout en restant **pixel-perfect** (orange/brun, blanc/orange, brun/blanc…). Recommandé.
3. **Vectoriel** : `corica-pattern.svg` en masque → net à toute taille, sans raster.

```css
/* Bande séparatrice recolorable, pixel-perfect */
.corica-band {
  height: 22px;
  background-color: #F26322;          /* couleur du motif */
  -webkit-mask: url("brand-assets/corica-pattern-strip.png") repeat-x left center / auto 100%;
          mask: url("brand-assets/corica-pattern-strip.png") repeat-x left center / auto 100%;
}
```
